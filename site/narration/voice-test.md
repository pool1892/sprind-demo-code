# Voice test passage

The same passage is read by each candidate voice (`tools/film-narrate voices`), so the
voice can be chosen by ear. About thirty seconds at a normal pace.

## voice-test: Voice test

This is a simulated robot installation. The robot's policy is fixed. Agents observe
it, run experiments, and change how the installation uses it. The obvious way to chain
two skills switches to the next one the moment the first reports success. That signal
is what published scores count. But it can fire while the hand still holds the item,
and the job ends wrong. A success signal is not a delivery.
